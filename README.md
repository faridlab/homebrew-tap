# faridlab/tap

Homebrew tap for [DIT — Done in Git](https://github.com/faridlab/dit-cli): local-first
project management kept as Markdown in git.

```bash
brew install --cask faridlab/tap/dit
```

This installs **DIT.app**, a menu bar app that starts and stops DIT and opens it in your
browser, and puts the `dit` command on your `PATH`.

DIT is not notarized by Apple yet. The cask therefore clears macOS's download quarantine
from DIT's own app bundle — after Homebrew has checked the download against its sha256 —
so the app opens without a security prompt. See
[ADR 0029](https://github.com/faridlab/dit-cli/blob/main/docs/adr/0029-menu-bar-app-and-homebrew-tap.md).

The cask here is generated by DIT's release workflow from
[`packaging/homebrew/dit.rb`](https://github.com/faridlab/dit-cli/blob/main/packaging/homebrew/dit.rb).
